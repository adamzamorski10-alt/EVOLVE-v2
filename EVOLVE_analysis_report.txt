2. ARCHITEKTURA SYSTEMU
================================================================================

Typ: FastAPI backend + monolityczny HTML/JS SPA frontend

Stack technologiczny:
- Backend:  FastAPI 0.110+, SQLModel 0.0.18+, SQLAlchemy, Pydantic v2
- Baza:     SQLite (dev) / PostgreSQL (prod) via DATABASE_URL
- Frontend: Jeden plik app/index.html (~26 600 linii, ~1.89 MB)
            Tailwind CSS CDN + Chart.js CDN, vanilla JS
- Auth:     JWT (access 30 min, refresh 60 dni) + PBKDF2 password hashing
- Dodatki:  Discord bot (discord.py), AI via Groq/Gemini, rate limiting (slowapi)

Struktura katalogów:
app/
├── __init__.py              # Inicjalizacja FastAPI, CORS, except handlers
├── config.py                # Settings, constants
├── database.py              # Engine, session, migrations, backfill
├── models.py                # SQLModel tables (UserDB, DailyLogDB, etc.)
├── schemas.py               # Pydantic schemas
├── legacy_routes.py         # 3 144 linii — "god file" (plan, AI, dieta, drills)
├── exercise_descriptions.py # 36 KB — statyczna baza ćwiczeń
├── auth/                    # JWT, password, dependencies
├── fitness/                 # routes (1 742 linii), calculations, dashboard
├── plan/                    # routes (296 linii)
├── ai/                      # routes, service
├── notifications/           # Discord, reminders

5. BEZPIECZEŃSTWO
================================================================================

ZALETY:
✓ JWT z sub=user_uuid, type=access|refresh, jti
✓ get_current_user dependency poprawnie odrzuca refresh tokens
✓ PBKDF2-SHA256 z 260 000 iteracji — silne hashowanie
✓ Rate limiting na register (5/hr) i login (10/min, 50/hr)
✓ Wszystkie protected routes pobierają user z JWT sub, nigdy z request body
✓ Brak SQL injection — wszystkie zapytania przez ORM lub parameterized
✓ Test_security_isolation.py: 18 testów weryfikujących izolację kont

PROBLEMY:

[HIGH] InsecureKeyLengthWarning
  - Testy emitują ostrzeżenie: HMAC key ma 23 bajty (minimum 32)
  - W produkcji secrets.token_hex(32) generuje 64 hex chars = 32 bajty ✓
  - Ale jeśli JWT_SECRET_KEY env var jest ustawiony na krótki string → osłabienie

[HIGH] datetime.utcnow() deprecation
  - jwt_utils.py używa datetime.utcnow() — deprecated w Python 3.12+
  - Zostanie usunięte w przyszłych wersjach Pythona
  - Wymaga zmiany na datetime.now(datetime.UTC)

[MEDIUM] Brak JWT revocation/blacklist
  - Brak mechanizmu unieważnienia skompromitowanych tokenów
  - jti jest generowane ale nigdy nie sprawdzane

[MEDIUM] CORS domyślnie na *
  - config.py:67: CORS_ORIGINS = os.getenv("CORS_ORIGINS", "*").split(",")
  - Jeśli env var nie jest ustawiony w prod → wszystkie origins allowed

[MEDIUM] Race condition w XP updates
  - Obecny wzorzec read-modify-write może tracić XP przy równoczesnych requestach

[LOW] Brak length validators na name field
  - ProfileUpdateRequest.name nie ma max_length

[MEDIUM] 12 skipped test files
  - Duża część funkcjonalności nie jest testowana

7. PROJEKT API
================================================================================

Endpointy dodane w tej sesji:

POST /app/exercise-set
  - Zapisuje pojedynczą serię ćwiczenia
  - Request: ExerciseSetRequest (exercise_name, set_number, reps, weight_kg, rpe, session_date)
  - Response: {status, set: {id, exercise_name, set_number, ...}}
  - Ownership: z JWT sub, nie z request body

POST /app/workout/complete
  - Finalizuje sesję treningową
  - Request: WorkoutCompleteRequest (session_date, exercises[], notes)
  - Response: {status, session_date, exercises[], total_volume_kg, avg_rpe, xp_earned, exercises_count}
  - IDEMPOTENTNY: aktualizuje istniejące ExerciseResultDB zamiast duplikować
  - Przyznaje 50 XP za workout completion

GET /app/workout/history
  - Zwraca historię sesji pogrupowaną po dacie
  - Query: ?limit=20&offset=0
  - Response: {sessions: [{date, exercises[], exercises_count, total_volume_kg, avg_rpe}]}

PROBLEMY API:
[MEDIUM] Inconsistent naming — niektóre endpointy używają hyphens, inne underscores
[MEDIUM] Brak tagów na niektórych routes (auto-generated docs mniej użyteczne)
[LOW] Niektóre endpointy są deprecated ale nadal aktywne
